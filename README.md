# AI 장중 모의매매 DEMO

## 현재 제공 범위
- 스마트폰 브라우저에서 볼 수 있는 Streamlit 대시보드
- 코스피/코스닥으로 구분된 **가상 종목 30개**
- 5초마다 변하는 합성 가상 시세
- 추세 35점, 모멘텀 25점, 거래량 30점, 위험도 10점의 점수화
- 모의 자동매수/매도, 보유현황, 체결 로그, 일일 손실 제한
- 초기 모의자금 500,000원

## 중요
이 프로그램은 실제 코스피·코스닥 종목을 스캔하거나 실시간 시세를 수신하지 않습니다.
종목명, 코드, 가격, 거래량은 전부 가상 데이터이며, 실제 증권계좌 주문 기능은 없습니다.
화면의 '실시간' 갱신은 가상 시세의 주기적 갱신을 뜻합니다.

## 로컬 실행
Python 3.11 권장

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Render 배포
1. 이 프로젝트를 GitHub 저장소에 업로드합니다.
2. Render에서 New > Blueprint 또는 Web Service를 선택합니다.
3. 저장소를 연결합니다. `render.yaml`을 읽으면 기본 설정이 적용됩니다.
4. 배포 후 발급된 HTTPS 주소를 스마트폰 브라우저에서 엽니다.
