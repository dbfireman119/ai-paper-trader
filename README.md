# AI 장중 모의매매 DEMO

## 현재 제공 범위
- 스마트폰 브라우저에서 볼 수 있는 Streamlit 대시보드
- 코스피/코스닥으로 구분된 **가상 종목 30개**
- 5초마다 변하는 합성 가상 시세
- 추세 35점, 모멘텀 25점, 거래량 30점, 위험도 10점의 점수화
- 모의 자동매수/매도, 보유현황, 체결 로그, 일일 손실 제한
- 초기 모의자금 500,000원

## 중요
이 프로그램은 실제 코스피·코스닥 종목을 스캔하거나 실시간 시세를 수신하지 않습니다.
종목명, 코드, 가격, 거래량은 전부 가상 데이터이며, 실제 증권계좌 주문 기능은 없습니다.
화면의 '실시간' 갱신은 가상 시세의 주기적 갱신을 뜻합니다.

## 로컬 실행
Python 3.11 권장

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Render 배포
1. 이 프로젝트를 GitHub 저장소에 업로드합니다.
2. Render에서 New > Blueprint 또는 Web Service를 선택합니다.
3. 저장소를 연결합니다. `render.yaml`을 읽으면 기본 설정이 적용됩니다.
4. 배포 후 발급된 HTTPS 주소를 스마트폰 브라우저에서 엽니다.

## 다음 개발 단계
1. NH투자증권 공식 API의 계정 권한/시세 API/모의투자 지원 여부 확인
2. 가상 종목 공급자를 실제 코스피·코스닥 종목 마스터 및 시세 공급자로 교체
3. 주문 체결 가정에 수수료·거래세·호가 스프레드·슬리피지 반영
4. 최소 20거래일 이상 모의운영 및 성과 검증
5. 사용자의 별도 승인 후에만 실계좌 연동 검토

API 키, 계좌번호, 비밀번호 등 인증정보를 코드나 채팅에 올리지 마세요.


## AI 헤지펀드형 모의매매 (실험용 5번째 계좌)
- 기존 안정형·공격형·스캘핑형·정밀 스캘핑형 계좌를 유지하고 독립된 AI 헤지펀드형 가상계좌를 추가합니다.
- 추세·모멘텀·거래량/유동성 분석, 상승론·하락론 점수, 리스크 게이트, 펀드매니저 합의 점수를 이용합니다.
- 현재 구현은 기존 NH 시세 데이터만 사용하는 **규칙 기반 멀티 에이전트 프로토타입**입니다. LLM 호출, 재무제표 분석, 뉴스 분석, 투자심리 분석은 아직 연결되어 있지 않으며 TradingAgents 원본 프레임워크의 완전한 재현이 아닙니다.
- 모든 매수·매도는 가상계좌 내부에서만 처리하며 NH투자증권 주문 API를 호출하지 않습니다.
- 실제 운용 적합성을 판단하기 전에 최소 20~60거래일 동안 체결·수수료·세금·슬리피지 가정을 포함해 비교 검증해야 합니다.
